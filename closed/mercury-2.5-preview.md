# Mercury 2.5 Preview

Preview of the diffusion-reasoning LLM line from Inception. It refines tokens in parallel rather than sequentially, for much lower latency. 260K context. Closed weights, API only. Priced at $0.04/$0.15 per M tokens on OpenRouter, roughly one-sixth the cost of Mercury 2.
