# Gemini 4 Argon

New Google frontier flagship and the first model of the Gemini 4 family, released Oct 13, 2026. Positioned for deep, multi-step work across coding, finance, legal, cybersecurity, and science. Globally available via the Gemini API in AI Studio and Gemini platform, Google Antigravity, and the Gemini app.

## Availability
- OpenRouter id `google/gemini-4-argon` at $2.00/$10.00 per M, 1M context.
- Google Cloud model id `gemini-4-argon`; cached input tokens at 95% off.
- Closed API (Proprietary) — no open weights.

## Pricing
- Introductory $2/$10 per M through Nov 30, 2026; standard $4/$20 after.
- On OpenRouter at the intro rate $2/$10 — undercuts GPT-6 Astra ($10/$50) and Fable 5.1 ($10/$50), and matches Opus 5.5 ($4/$20) on cost while being the newest frontier launch.

## Capabilities
- Frontier coding: large codebase refactoring, parallel multi-file changes. Google reports Argon in Antigravity increased agentic code submissions by 35%+ while cutting rollbacks ~1/3; Chrome used it to refactor a ~6M-line legacy folder in Chromium's 40M-line codebase.
- Long-horizon agentic work with an industry-leading 1M unified input+output token limit.
- Multimodal with deep visual perception; improved spatial reasoning, math precision, and visual coding (3D/Blender/ray-tracing demos).
- Trained to respect system boundaries, report negative findings honestly, and pause before irreversible steps (2% shortcut attempts on coding benchmarks — best of prior Gemini).
- Strongest prompt-injection resistance: leads Gray Swan IPI at 0.7% attack success across 15 adaptive attempts.
